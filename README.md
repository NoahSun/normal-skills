# normal-skills

**Skills for addressing challenges encountered in practice**

## 📖 Introduction

**Normal Skills** is a collection of Agent Skills for AI coding agents, maintained by [NoahSun](https://github.com/NoahSun).

This package includes skills for addressing challenges encountered in practice. Each skill is a self-contained `SKILL.md` file that AI agents load on-demand.

## 📦 Install

```
npx skills add NoahSun/normal-skills
```

Or install specific skills:

```
npx skills add NoahSun/normal-skills --skill <skill-name>
```
